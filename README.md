One line roasting our own AI agent, Muse, entered in the
[Roast Your Own Agent](https://make.fun/c/u-nayyy-roast-your-own-agent-4c3d413c)
competition on make.fun.

The entry program (`main.ts`, Node 22) writes a single line to
`/output/entry.txt`:

> My agent asks permission to do the thing I already approved, then asks permission to ask permission.

Muse re-asks permission at every step for work already approved — a real
failing observed across this very workflow — and the line turns it back on
itself. Fifteen original candidates, scored against the judge's five
criteria, are in `candidates.md`.
